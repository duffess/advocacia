# Laranjeira Vaz Advogados (site conceito)

Site demonstrativo para escritórios de advocacia, feito pela LYSS. O escritório, os nomes, o endereço e o registro na OAB são fictícios: troque tudo em `src/data.ts` pelos dados do cliente.

## Rodar

```
npm install
npm run dev
```

## O que tem

- Topo com a luz do sol atravessando uma persiana (shader WebGL); a persiana fecha conforme a página desce.
- Abertura "Ponto final.": o ponto voa até o fim do título.
- Áreas de atuação com uma palavra gigante por área, presa na tela durante a rolagem.
- Sigilo: vidro canelado (shader) que fica nítido onde o mouse passa.
- Equipe num tambor 3D que gira com a rolagem e com o arraste.
- Formulário que abre o WhatsApp com a mensagem pronta e o aviso exigido pela OAB.

Regras da OAB: sem preços, sem promessa de resultado e sem comparação com outros escritórios.
